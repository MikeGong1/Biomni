# Limitations

Public evidence cannot reveal private repositories or forks, deleted material,
un-pushed local code, hidden organization membership, private product code, or
undisclosed commercial architecture. “All contributors” and “all members” in this
database therefore mean all publicly observable entries under the documented
queries, not all people who may exist.

GitHub counts and search results are time-dependent. Pagination is complete only
when the API or UI reports no next page/cursor; rate limits, deleted objects, and
search indexing may still affect observability. Each completed collection records
its observation time and pagination status.

Static source inventory proves that code or metadata is present at a SHA. It does
not prove successful installation, runtime correctness, service availability,
model quality, data availability, or compatibility with current dependencies.
Research-phase safety rules intentionally defer those questions.

README and product statements can describe intended capability but are weaker
than code-level evidence for implementation details. Third-party reports are lead
sources only. Unknown information remains `UNKNOWN` unless public evidence
supports a more specific classification.
